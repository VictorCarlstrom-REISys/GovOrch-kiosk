# 🖥️ Kiosk Display Application

A modern, responsive kiosk display experience designed and prototyped using **Figma Make** and built with **React.js**. This project delivers an intuitive touch-friendly interface optimized for large-screen kiosk environments, digital displays, and self-service experiences.

./assets/banner.png

## 🚀 Overview

The Kiosk Display Application was created to provide a seamless user experience for interactive display systems. The design originated in Figma Make and was translated into a production-ready React application with a focus on:

- User-centered design
- Large-screen accessibility
- Responsive layouts
- Fast performance
- Scalable component architecture
- Touch-first interactions

## ✨ Key Features

### User Experience
- Intuitive kiosk navigation
- Large touch targets and accessible controls
- Optimized visual hierarchy
- Responsive display layouts
- Smooth animations and transitions

### Technical Features
- React.js frontend architecture
- Component-based design system
- State management for real-time interactions
- Responsive design patterns
- Modular and maintainable codebase

### Accessibility
- WCAG-inspired design considerations
- Keyboard navigation support
- Screen-reader friendly markup
- High contrast visual options

## 🎨 Design Process

This project was designed using **Figma Make**, allowing rapid ideation, prototyping, and validation before development.

### Design Goals

- Create a simple, frictionless kiosk experience
- Minimize cognitive load for users
- Ensure visibility from varying distances
- Support touch interactions across screen sizes
- Maintain consistency through reusable components

### UX Principles Applied

- Recognition over recall
- Clear visual hierarchy
- Consistency and standards
- Error prevention
- Accessibility-first thinking

## ⚙️ Installation

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Clone Repository

```bash
git clone https://github.com/yourusername/kiosk-display.git
cd kiosk-display
```

### Install Dependencies

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

Application will be available at:

```text
http://localhost:5173
```

---

## 🔨 Build for Production

```bash
npm run build
```

Preview production build locally:

```bash
npm run preview
```

## 🚀 Deployment

This application can be deployed to:
